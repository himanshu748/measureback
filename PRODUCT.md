# MeasureBack

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Delegated by the user. Python standard library for recipe arithmetic, CALL E integration and a local HTTP server. Plain HTML, CSS and JavaScript for the browser. A public read only example can run without credentials.

## Users

An adult who wants to cook a consenting relative's unwritten recipe. Hackathon judges need a complete example that cannot place a call.

## Product Purpose

An ordinary phone call asks the cook to explain a recipe and clarify missing measurements. The resulting recipe keeps source quotations and only scales quantities that have a supported unit relationship.

## Positioning

The central mechanism is unresolved household measures becoming explicit, evidence linked quantities. Voice recipe transcription exists elsewhere. The contribution is adaptive measurement clarification and deterministic, dimension preserving serving arithmetic.

## Operating Context

The user chooses a recipe, an authorized phone contact and a preferred language. CALL E carries the conversation. The browser reviews recipe evidence and scales servings. The public judge path uses clearly labeled authored examples.

## Capabilities and Constraints

Scope: ingredient quantities, household measure calibration, exact source anchors, corrections, recipe step dependencies and serving arithmetic. Cooking times do not scale. Salt to taste remains to taste. Volume never becomes mass without a supported conversion. No nutrition, allergy safety, food safety certification or medical claims. No purchases or commitments. No hidden schedules. Live dialing requires explicit approval, consent, a permitted time window and a server side key.

## Evidence on Hand

No live cook interview has been recorded for this project. All initial recipes and transcript excerpts are authored fixtures, not family recordings or validation evidence.

## Product Principles

Preserve uncertainty. Show the cook's words. Keep arithmetic outside the model. Make the next missing question concrete. Make public evaluation safe without an account.

## Accessibility & Inclusion

Keyboard operable controls, readable contrast, responsive layout and reduced motion support. Language instructions will be configurable; supported live languages must be verified against CALL E documentation and not inferred from a prompt.
